Data Drift Detection

A DPA is signed once. A privacy policy is quietly reworded. A hiring page changes every week. This watches all three for every vendor you rely on — flags a rewritten clause the week it moves, and checks who can reach your data against the countries you actually allow. Every flag ends in a question to put to the vendor, not a verdict.

Loading collected data…

How it runs. A GitHub Actions workflow fetches each vendor's privacy policy, DPA and sub-processor page, normalises them to one sentence per line and commits them to data/snapshots/. Because the snapshots are committed, git log -p on any file is a dated record of every wording change. The diff engine is git.

What this is not. Not a compliance assessment, not legal advice, and not an accusation. A contradiction on the surface usually has a dull explanation; the point is to give a reviewer the specific sentence and the specific posting so they can go and ask for it. Every flag is generated from public sources, with the source linked. Text extraction is imperfect and the collector says so when it cannot read a page rather than guessing.
