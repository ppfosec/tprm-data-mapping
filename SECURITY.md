# Security

## Reporting

Please report vulnerabilities privately through GitHub's security-advisory interface rather than opening a public issue.

## Data and model boundaries

This public repository contains fictional internal evidence and public vendor evidence only. Do not commit credentials, private heuristics, customer records or production connector exports.

Replay is the default execution mode and makes no model call. `live` and `record` require both an explicit mode selection and an API key. Model output remains evidence-bound and cannot promote itself into the curated judgment fixture.
